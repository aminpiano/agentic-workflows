# Examples

This folder is intentionally light. Full research runs can contain private sources and should usually remain outside the public repository.

Start with:

- `templates/authority-research/domain-map.yaml`
- `templates/ai-docs/SPEC.md`
- `templates/seogo/seogo_index.md`

Then create a local run under `data/authority-research-runs/`.

Generated runs are ignored by git by default.
